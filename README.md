# Northern Suppliers website

Live site files for northernsuppliers.net.au (Mareeba and Atherton).

- `index.html` is the whole site. Product data is the `PRODUCTS` list near the top of the script.
- `img/` holds product photos at 800px, named by REX product ID; `img/t/` holds the 160px thumbnails.
- `404.html`, `robots.txt`, `sitemap.xml` and `manifest.webmanifest` are served as-is.

Hosted with GitHub Pages from the `main` branch.
